구독 방법

  • 구글 캘린더 — 다른 캘린더 + → URL로 추가 → 위 주소 붙여넣기
  • 아이폰 — 설정 → 캘린더 → 계정 → 계정 추가 → 기타 → 구독 캘린더 추가
  • 네이버 캘린더 — 설정 → 캘린더 관리 → 구독 캘린더 추가

구독이라 읽기 전용입니다. 노션에서 고치면 다음 갱신 때 반영됩니다.
